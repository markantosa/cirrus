CIRRUS Model Math (Judge-Friendly)

Only the equations needed to explain why each model is valid for our problem

Subsystem A: Gradient Boosting Regression

f_M(x) = f_0(x) + Σ[m=1..M] ν · h_m(x)
r_im = y_i - f_(m-1)(x_i)
f_m(x) = f_(m-1)(x) + ν · h_m(x)
Action(y_pred): DUMP if y≤20, TOP-OFF if 20<y≤50, CONTINUE if y>50
Meaning: learns nonlinear bath degradation, then converts prediction to operations.

Subsystem B: Random Forest Classification

ĉ(x) = mode{ ĉ^(1)(x), ĉ^(2)(x), ..., ĉ^(T)(x) }
P(c_k|x) = (1/T) Σ[t=1..T] 1(ĉ^(t)(x)=c_k)
Gini: G = 1 - Σ[k=1..K] p_k²
Split gain: ΔG = G_parent - (n_L/n)G_L - (n_R/n)G_R
Meaning: robust multiclass routing with confidence scores for ORC/DI/HVAC/BLEND.

Shared Preprocessing

z_j = (x_j - μ_j) / σ_j
  • Normalizes different sensor scales
  • Prevents high-range signals from dominating
  • Supports stable training for both subsystems

Evaluation Metrics

MAE = (1/n) Σ |y_i - ŷ_i|
R² = 1 - [Σ(y_i-ŷ_i)² / Σ(y_i-ȳ)²]
Precision = TP/(TP+FP), Recall = TP/(TP+FN)
F1 = 2PR/(P+R)
Meaning: A is judged by prediction error, B by routing classification quality.
